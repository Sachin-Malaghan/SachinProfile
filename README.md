# Sachin's Portfolio

C++, Unreal Engine 5, real-time 3D and game development.

- `site/` is the website (plain HTML, JavaScript and media, no build step). Netlify publishes this folder, as set in `netlify.toml`.
- `_source/upwork-covers/` has 4:3 cover images for Upwork, Fiverr and LinkedIn.
- `_source/store-screenshots/` has full-size Hollowlight screenshots.
- `_source/tools/` has the scripts that generated the images, videos, trailer and store art.

Run locally: `python -m http.server 8000 --directory site`, then open http://localhost:8000
